# Nori / Journey Atlas

Journey Atlas (01) is the selected dashboard direction. The concept switcher and alternative journey layouts have been removed.

Open http://127.0.0.1:4174/#1 with the local server running, or open index.html directly. No dependencies or build step are required.

## Features
- Home, Journeys, Runs, and Websites navigation.
- Rounded attached-persona pills with issue counts.
- Overview and Live view floating controls.
- Connected stage map with persona filtering and fictional findings.
- Simulated per-person browser frames, play/pause, stepping, and captured moments.
- New sample-run setup with URL validation and persona selection.

All data and browser frames are illustrative. No agents run, no website is visited, and no data is persisted. The homepage is unchanged.

Validation: JavaScript syntax and all four workspace views in both journey modes render successfully.
